# Samples

See [../docs/SAMPLES.md](../docs/SAMPLES.md) for the sample catalog, learning path, and validation commands.

The samples are source examples, not automatically built programs. `make full` copies their source files into the image under `/samples`; use `make check-samples` for syntax and structural checks, then compile or run each example with the toolchain described in [the complete catalog](../docs/SAMPLES.md).
