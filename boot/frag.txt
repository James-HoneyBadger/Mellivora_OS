HBFS v4 extents - a file that is three runs
==========================================

This file is here to be read off a v4 volume whose directory entry does not
point at its data directly: the entry names an extent block, and the extent
block names three runs of one block each. A reader has to walk that list to
find the block an offset falls in, and a reader that ignores it reads the
extent block itself as if it were the file.

Nothing about these lines is special except how many there are: the file is
longer than a block, which is the only excuse the builder needs to split it.
The first line and the last line are in different runs, so a read that stops
at the first one is caught by the test that reads this file.
